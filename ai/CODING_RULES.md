# AUREXIS Coding Standards

- TypeScript strict mode
- Python type hints for application/business code
- Validate external input
- Use migrations for database changes
- No magic trading constants; configuration must be explicit
- No secret values in source
- Structured logging
- Explicit error handling
- Idempotent command handling
- UTC timestamps
- Precise monetary representation
- Small modules with clear responsibilities
- Tests accompany business logic
- Avoid duplicated business rules
