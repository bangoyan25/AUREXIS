# AUREXIS Implementation Protocol

For each task:

1. Read relevant specs and locked decisions.
2. Restate the task in implementation terms.
3. List files/components to change.
4. Identify assumptions and undefined requirements.
5. Implement the smallest complete change.
6. Add/update tests.
7. Run tests and static checks.
8. Review for security and risk bypass.
9. Report:
   - changed
   - tested
   - not tested
   - known limitations
10. Mark task complete only when acceptance criteria are satisfied.
